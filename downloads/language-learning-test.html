How it works

  • Choose one of four answers. Feedback appears immediately and the next prompt appears after 0.5 seconds. Answers are reshuffled each time.
  • Each lesson is a ten-question block. Ten correct answers in a row complete it.
  • A mistake restarts the current block at question one and resets the consecutive count. The third mistake in the same block restarts at lesson one, question one—even if correct answers came between the mistakes.
  • Mistakes remain counted when a wrong answer restarts the same block. A new block, manual restart or third-mistake return to lesson one clears the count. Browser progress is not saved.
