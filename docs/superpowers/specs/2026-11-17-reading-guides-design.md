# Source-language reading guides

Owner-approved conversation design, 2026-11-17: guides only for lv-ru (Latvian letters), ru-en (Cyrillic approximations) and en-ja (romaji). Original seven learning directions remain. Every Japanese kana has its own reading directly underneath; small kana carry role notes and irreducible kanji readings may span a group. Guides teach sounds, not character meanings. Audio remains the pronunciation reference; human review is pending.

Separate per-direction/per-block guide modules keyed by permanent concept IDs are chosen over changing translations or generating live transliterations. This supports ten-item review batches, preserves identity and avoids network/runtime dependencies. One loader validates exact original target text, coverage, direction and Japanese segmentation. The renderer uses text nodes only, beneath all four target answers; no source-prompt aids (the learner already reads the source). Guide scripts and role explanations use the source language (en-ja romaji marked ja-Latn). Screen readers retain the original answer name, with a source-language reading description. Speaker buttons remain independent.
