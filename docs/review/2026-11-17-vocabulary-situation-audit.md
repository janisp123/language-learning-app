# What situations the current vocabulary can support

Read-only content assessment by Codex, 17 November 2026. Reviewed all 500 active meanings and their Latvian/Russian/English translations at commit `6b2b217c6ca5a561256b897219c3faf9d8fa0341`. Canonical translations match main; the review branch only changes their UI version labels. This report changes no vocabulary, translations, order, task authorization or learning behavior.

**Overall finding:** The bank is a useful foundation for short, cooperative everyday exchanges. It is especially useful for locating places, requesting familiar items, naming needs and understanding simple direction words. Its main weakness is the small number of reusable communication frames relative to the amount of naming vocabulary. Understandable fragments count as useful communication under the owner's goal; grammatical completeness is not the grading standard for this audit.

These are capabilities supported by the material, not measured learner outcomes. Translation/pronunciation review is still pending. No proficiency level or percentage of real-life situations has been established.

**What is actually in the bank**

- 50 blocks, ten items per block; 500 meanings translated into LV/RU/EN.
- Authoring tags: 426 `word` entries and 74 `phrase` entries. Forty of those phrase entries are infinitive verb labels in blocks 42–45. Other phrase entries include names such as bus stop and traffic lights, as well as useful utterances. Thus 74 phrase tags do not mean 74 ready-made requests or conversation patterns.
- Broad coverage includes 50 food/drink entries in blocks 6 and 23–26, 30 number entries, 40 action entries, 12 month names, ten animal names and ten colors. These counts describe the inventory, not a frequency ranking or a claim that each category has equal learning value.
- The first 100 items cover greetings, people, numbers one–ten, useful words, essential places, food/drink, classroom items, directions, safety and question words. They already support useful fragments before the whole bank is learned.

**High-value gaps and reuse opportunities**

These are recommendations for discussion, not approved additions or implementation tasks. Keep the scope small; a fixed count of 500 should not encourage padding or prevent a few better-prioritized items.

1. **A usable “I don't understand” frame.** The bank has “to understand” (0430), no (0007) and not now (0264), but these are not an explicitly taught negated-understanding pattern. General negation occurs inside the fixed not-now chunk; it is not taught as a freely reusable frame. Existing again/more slowly/please already cover the complementary repair requests.
2. **One “I need…” frame.** Need/want/can/have meanings are absent as taught concepts. One request frame could connect existing water (0051), help (0031), doctor (0086), ticket (0380), toilet (0049) and phone (0171). Adding all of those auxiliary/request alternatives at once would work against the goal of economical reuse. Item + please already handles many requests; this is an improvement in clarity and flexibility, not a claim that the current bank cannot request anything.
3. **A minimal “Call …, please” request.** Call is absent, while the service/person/phone vocabulary is already present. This connects the safety labels to an action another person can take.
4. **Precise allergy/restriction language.** Allergy is absent. “Without me” (0486) is an existing chunk containing the preposition, but the course does not teach a general without-X substitution pattern. Reusing current food words with such a pattern has more practical leverage than merely adding more food names.
5. **A brief lost/self-identification/language-repair set if these situations are a priority.** Lost and name are absent as taught meanings. The UI names the languages, but the 500 learning items do not directly teach asking for communication in Latvian/Russian. These are possible narrow follow-ups, not a proposal for a broader curriculum.

**Ordering affects the useful minimum**

- “Please help” is item 0261, in block 27; “more slowly” is 0263. The early help noun 0031 and slowly 0039 remain useful, but the direct phrases arrive late.
- The forty main action entries are 0411–0450, blocks 42–45.
- I/you/he/she/we/they arrive at 0491–0496, in the final block.

Because blocks are sequential, a learner who only reaches the early blocks will not yet have encountered those later tools. For a future revision, the useful question is whether an early compact core should include more recombinable requests before additional lists of objects, months or animals. No order or IDs have been changed by this audit. Any reordering must respect the existing identity locks and be reviewed as an intentional content change.

**Meaning/form review candidates**

The review did not establish widespread LV↔RU meaning failures. Dictionary forms and understandable fragments should not be rejected merely for imperfect grammar. The following are bounded usability/context questions:

| Item | Observation | Assessment |
| --- | --- | --- |
| 0158 thirsty: `izslāpis / испытывающий жажду` | Russian is a comparatively cumbersome participial description for a simple need | Shared meaning is recognizable; review production usefulness rather than call it a mistranslation. A water request already gives the learner a practical alternative. |
| 0413 to walk: `staigāt / гулять` | The Russian commonly suggests walking/strolling for leisure | Clarify intended use before assuming it covers walking as transport. |
| 0177 battery: `baterija / батарейка` | Positioned among phone/device words, while Russian often suggests a replaceable battery | Clarify which object is intended before changing the translation. |
| 0433 to watch: `vērot / наблюдать` | LV/RU align on observing; English watch may suggest television | Clarify the meaning/context; do not automatically label the pair wrong. |

**How this relates to the repetition goal**

The current bank can supply useful words for short exchanges. The app's visible-word/four-choice exercise directly checks translation recognition; its current-prompt speaker supplies pronunciation on request. Automatic speaking, listening without visible text and successful use with another person are separate outcomes that have not been measured. A practical evaluation would ask learners to locate a place, request an item, ask for slower speech and get help using a small subset they have practised. This is an evaluation suggestion, not authorization to add tracking or saved progress: the zero-saves rule remains in force.
