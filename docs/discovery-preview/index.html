The approach

Build familiarity.
Keep coming back.

Start with survival basics and keep practicing familiar words. Being understood matters more than perfect grammar or elegant phrasing.

01

Start with the essentials

Each fresh session begins at lesson one, revisiting familiar material before moving on.

02

Practice until it sticks

Choose from four reshuffled answers. Ten correct answers in a row complete a lesson. A mistake moves you back one prompt and resets the run. Three mistakes in the same ten-question block restart you at lesson one, question one.

03

Use it in everyday life

The course is being designed around things you might need to say—and understand—at school, with friends and around town.

Browser: a fresh start

Browser practice saves no progress. Reopening or refreshing begins at lesson one.

Zero saved progress

Every platform starts a new session at lesson one. Progress stays only in current session memory, with no saved record, backup or restore. The planned Android app follows the same rule.

Practice without point chasing

No XP, leaderboards, lives or daily streak rewards. The focus is returning to useful language.

A few things to know

Before you begin.

Can I start learning now?

You can try the draft browser build using the link above, or download its HTML file and open it in a browser. No installation is needed. Human language review and device testing remain pending; this is not a finished release.

Who is the first course for?

The first learning path is for ages 10–17, focused on everyday situations relevant to young people in Latvia. The test build supports all six directions between Latvian, Russian and English, plus English → Japanese with script-only answers. Its interface follows the language you start from.

Will it be free?

Yes. Browser practice has no ads, subscriptions or payments. Source-code and learning-content reuse licenses have not been chosen yet; a public repository does not grant a reuse license.

Does this page collect information?

This page has no forms, scripts, analytics, cookies or external fonts. GitHub Pages and GitHub handle requests when you visit their services; this page does not ask for personal details.
