The approach

Build familiarity.
Keep coming back.

The planned method uses cumulative repetition, with useful phrases at the centre of every session.

01

Start with the essentials

Each fresh session begins at lesson one, revisiting familiar material before moving on.

02

Practice until it sticks

Choose from four reshuffled answers. Ten correct answers in a row complete a lesson. A mistake moves you back one prompt and resets the run.

03

Use it in everyday life

The course is being designed around things you might need to say—and understand—at school, with friends and around town.

Designed to stay simple

Room to learn.
Less to manage.

The first release is planned without accounts, ads, payments, tracking or a remote progress database.

Browser: a fresh start

Browser learning is planned without saved progress. Reopening or refreshing will begin at lesson one.

Android: only your highest lesson

The Android app is planned to retain only the highest lesson reached, with manual file export and import. Every new session will still start at lesson one.

Practice without point chasing

No XP, leaderboards, lives or daily streak rewards. The focus is returning to useful language.

A few things to know

Before you begin.

Can I start learning now?

Not yet. This page introduces the planned course. Working browser lessons and an Android app will be linked here when they are released and verified.

Who is the first course for?

The first learning path is for ages 10–17, focused on everyday situations relevant to young people in Latvia. It is planned to support both Latvian-to-Russian and Russian-to-Latvian practice.

Will it be free?

Yes. The planned first release has no ads, subscriptions or payments. Source-code and learning-content reuse licenses have not been chosen yet; a public repository does not grant a reuse license.

Does this page collect information?

This page has no forms, scripts, analytics, cookies or external fonts. GitHub Pages and GitHub handle requests when you visit their services; this page does not ask for personal details.
