# Original draft curriculum — archived

This is the original ten-block, 100-prompt curriculum from the modular browser test build, preserved at the owner's request to avoid changing the meanings of existing IDs.

The owner subsequently replaced the active beginner curriculum with 500 basic words/short phrases in 50 blocks, including phrase/word-only introductory blocks. The replacement has a new course ID and new question/concept IDs. Nothing in this archive is included in the current browser build.

`tests/fixtures/original-content-lock.json` is unchanged. The original-content regression test assembles this archived `content/` tree and verifies the original ID/text/answer digest. Do not reuse these IDs for different meanings or edit archived records to make a new curriculum pass.

Archived translations and UI remain drafts; this snapshot is history, not a release or an alternative current source.
